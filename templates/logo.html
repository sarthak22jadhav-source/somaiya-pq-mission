Regenerating the artwork

The mark is fully reproducible from source

logo_generator.py paints the mark on a Tkinter canvas and captures it straight from the window device context, so the PNG is pixel-identical on every run. The starfield is seeded with a fixed random sequence and the artwork is drawn at 900 × 420 pixels. 

python logo_generator.py                          # writes static/logo.png
python logo_generator.py --size 1200x560         # custom canvas size
python logo_generator.py --print-palette         # list the colour palette

The dashboard also regenerates the file automatically on start-up whenever static/logo.png is missing.
